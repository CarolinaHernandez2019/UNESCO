# Convocatoria UNESCO Santiago — Estadísticas educativas y monitoreo ODS 4

Página informativa sobre la consultoría STG/2026/CIC/05 de UNESCO Santiago. Sistematiza el contexto institucional, las siglas relevantes, la metodología del SIRIED, las cifras del Informe regional ALC y los indicadores del marco de monitoreo del ODS 4.

## Contenido

- **Convocatoria**: datos generales y funciones del rol
- **Unidad**: contexto de UNESCO Santiago y sus iniciativas clave
- **Glosario**: siglas organizadas por tema (ODS, sistemas de información, discapacidad, evaluaciones, cooperación)
- **SIRIED**: explicación detallada del Sistema Regional de Información Educativa de estudiantes con discapacidad
- **Cifras**: datos del Informe regional *La encrucijada de la educación en ALC* (UNESCO/UNICEF/CEPAL, 2022)
- **Indicadores**: marco de indicadores ODS 4 más citados

Abrir `index.html` directamente en el navegador. No requiere servidor local ni build step.

## Publicación en GitHub Pages

Una vez en el repo, activar GitHub Pages desde Settings → Pages, escogiendo la rama `main` y la raíz del repo. La URL será `https://<usuario>.github.io/convocatoria-unesco-santiago/`.
